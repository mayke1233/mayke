# Quórum

Escritório virtual de agentes para sellers de marketplace. Seis agentes com função própria se reúnem todo dia, operam a conta dentro de regras de margem e deixam na fila só o que passa da alçada.

A conta Casa Lume, os números e as decisões são fictícios. O pedido de demonstração fica apenas no navegador.

## Rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`. O escritório interativo fica em `/escritorio`.

```bash
npm run build
```
